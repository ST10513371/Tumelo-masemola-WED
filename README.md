# 1. Project Overview

## About The Gaming Club

The Gaming Club is a fictional gaming lounge created as part of a web development Project. The purpose of the website is to provide gamers with information
about the gaming lounge, the games available, gaming facilities, prices and upcoming
gaming tournaments.

The website is designed to create a fun and modern online experience for people who
enjoy gaming and want a place where they can play games with their friends.

The website allows visitors to explore the gaming facilities, view featured games,
check available gaming packages and prices, learn about upcoming tournaments and
make an enquiry about a gaming session.

The website is intended for a fictional business and is not currently being used as
a real commercial website.

# 2. Website Goals and Objectives

The main goal of The Gaming Club website is to create an attractive and easy-to-use
website that gives visitors useful information about the gaming lounge.

The objectives of the website are:

- To introduce visitors to The Gaming Club.
- To provide information about the gaming facilities available.
- To display some of the games available at the gaming lounge.
- To provide visitors with gaming prices and packages.
- To promote gaming tournaments and events.
- To allow visitors to make enquiries about gaming sessions.
- To provide contact information for the organisation.
- To create a simple, attractive and easy-to-navigate website.

# 3. Key Features and Functionality

The Gaming Club website contains the following features:

### Home Page

The home page introduces visitors to The Gaming Club and provides a short
description of the gaming lounge.

It includes:

- Welcome message
- Gaming slogan
- Hero section
- "Book a Session" button
- "Explore Games" button
- Navigation menu

### About Us Page

The About Us page provides information about The Gaming Club.

It includes:

- Background of the organisation
- Mission
- Vision
- Target audience
- Information about the gaming experience

### Contact Us Page

The Contact Us page provides ways for visitors to contact The Gaming Club.

It includes:

- Contact information
- Email address
- Phone number
- Location information
- Contact form

### Enquiry Page

The Enquiry page allows visitors to submit an enquiry.

The form can be used to request information about:

- Gaming sessions
- Gaming packages
- Tournaments
- General enquiries

### Games & Services Page

The Games & Services page provides information about what The Gaming Club offers.

It includes:

- Gaming PCs
- PlayStation 5
- Xbox
- Group gaming
- Featured games
- Gaming prices
- Gaming packages
- Tournament information

# 4. Website Navigation / Sitemap
The main navigation menu contains:

Home
About Us
Games & Services
Enquiry
Contact Us

The main buttons also link visitors to relevant pages.

For example:
"Book a Session" → Enquiry page
"Explore Games" → Games & Services page
"Book Now" → Enquiry page
"Enter Tournament" → Enquiry page
